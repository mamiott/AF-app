# アスリート栄養クイズ

アスリートの栄養をテーマにした4択クイズアプリ（全10問）です。

## 使い方

`index.html` をブラウザで開くだけで遊べます（インストール不要）。

## 機能

- 4択クイズ（全10問）。選択肢は毎回シャッフルされます
- 回答ごとに正解・不正解と解説を表示し、効果音を鳴らします（ボタン操作・再挑戦の開始・結果発表にも効果音あり）
- 「🔊 音声で聞く」で問題文と選択肢を読み上げます
- 間違えた問題は最後にもう一度出題され、正解すると励ましの言葉が表示されます
- 結果画面では1周目の正解数と正答率に応じたメッセージを表示します

## ファイル構成

- `index.html` … 画面の構造
- `style.css` … 見た目
- `questions.js` … 問題データ
- `script.js` … クイズの動作
